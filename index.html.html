Bob Coin Analyzer

Pick your Bob database folder. Everything is read in this browser — nothing is uploaded.

bob.db — drop bob.db (and bob.db-wal if present) here, or use the buttons. Pick the wal file too so recent activity is included.

Default location: C:\Users\<you>\.bob\db

Coin figures come from the cost Bob records for each request. Savings are estimates assuming cost grows with context size. Thresholds are this app's defaults, not Bob rules. Plan allocations: Bobcoins docs.
